# House Price Prediction

## Intern ID
CITS9344

## Project Overview
A basic Machine Learning project that predicts house prices based on area, bedrooms, and age of the property, using Linear Regression.

## Files
- `house_price_prediction.py` — main script
- `house_data.csv` — dataset
- `requirements.txt` — dependencies

## How to Run
1. `pip install -r requirements.txt`
2. `python house_price_prediction.py`

## Tech Used
Python, Pandas, Scikit-learn
